# 声音家族与一致性

新声音方向、批量制作或听感不一致时读取。借鉴视觉文档的来源—角色—参数—配方—禁用项结构，不把色板、描边或视觉媒介机械映射成乐器。

## 声音简报

记录现行声音参考/选定母版及hash、对应体验、事件类别与消费者。实际听过的参考才描述听感；不能从文件名推断乐器、情绪或音质。区分全局混音关系、事件家族与单个音效例外。

| 维度 | 记录内容 |
| --- | --- |
| 身份 | 音色来源、材质感、乐器/合成方式、允许变化与不采用方向 |
| 角色 | 常规操作/关键反馈/音乐/环境/对白，谁应突出、谁让位 |
| 时间 | 起音、主体、尾音、节奏、重复时的变化、循环接点 |
| 频谱与空间 | 主要频段角色、干湿关系、混响尾部、声像/声道与单声道兼容 |
| 动态 | 相对音量、瞬态/持续声关系、并发叠加；绝对目标仅来自实际规范 |
| 交付 | 无损母版/可编辑源、导出规格、播放停止/静音契约、来源限制 |

不得为了“统一”把确认、失败和背景乐压成同一种强度，也不能凭视觉是复古就擅加黑胶噪声。用户选中的音色与台词是保护项。

## 配方和校准

每家族记录一份可复用的制作配方：音源/合成层→包络→适用处理链→导出与循环策略；只记实际工具支持的参数。新事件继承家族规则，分别列允许的音高、时长或力度变化；不凭空统一全项目LUFS。

批量先选代表事件，与已确认声音在同一播放增益下对照。必要的响度匹配只用于另存的试听副本并标注处理，不能静默归一化正式母版。分别检查音色统一、功能辨识、密集触发疲劳、音乐/对白遮蔽与循环首尾。没有实际试听能力就交可播放文件与待听项，不把波形检查当听感结论。

候选hash关联制作记录、技术测量与试听记录。声音变更后重新核对该候选；游戏内并发/后台恢复及设备音量由用户验收，桌面试听不能替代。已有资源覆盖保持工单边界。
