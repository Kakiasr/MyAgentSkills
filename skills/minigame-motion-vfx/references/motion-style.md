# 动效、VFX与材质的风格契约

新表现或整组统一时读取；只调一个已定义参数时复用原契约。外观由主美现行基线决定，本页把它翻译为TA可实现、可核对的输入，不修改玩法时序。

## 动态也有统一语言

记录视觉来源和动作意象（纸片弹起、板块按压等仅为描述示例，不是项目默认），说明它对应哪些形状、运动和材质特征。按用途分为常规交互、关键反馈、环境装饰，明确主次，避免所有效果同样抢眼。

| 维度 | 必须明确的应用信息 |
| --- | --- |
| 运动 | 方向/轨迹、幅度及坐标空间、锚点、阶段持续ms、缓动曲线、是否过冲及上限 |
| 形态 | 发射/展开轮廓、大小随时间、边缘硬度、是否使用现有图形母题 |
| 色与光 | 色彩职责、亮度层级、Alpha曲线、加色/普通混合、允许发光的范围 |
| 材质 | Shader属性映射、纹理职责、UV/空间、哪些层可噪声/渐变、哪些需保持硬边 |
| 节奏 | 起势/峰值/回落、输入反馈与结算事实的关系、叠加时优先级 |
| 生命周期 | 触发、去重、打断、退出状态、复用/重开/后台恢复 |

只填真实需要的维度，未知值标候选，不统一发明时长、亮度或粒子预算。CSS easing仅描述曲线，须明确Unity实际实现及映射，不能宣称复制字符串即可得到同样结果。

## 实现配方与负面边界

将一例效果写成「事件→实际属性唯一写入者→时间/形状/颜色曲线→停止/复位」，保留源参数与受影响消费者。区分位移层、缩放层、图形层，明确能否叠加。材质例外必须限定层与范围，不能一边要求平涂一边无条件叠全屏柔光。

成套动效继承同一组已确认节奏和形状规则；强弱变体只改变已指定参数。不要为了“活泼”让禁用元素继续跳动、扩大射线面、增加结算延迟或改变伤害次数。普通VFX不自动套贴纸半透明外缘。

## 验收

先核对曲线、属性写入和引用；已有实际预览时按起势/峰值/回落/停止取关键帧并记录时间，连续性仍需真实播放。静态分镜不能证明动效顺畅。批次对照轮廓、色彩、节奏和视觉优先级；逐项检查叠加、打断和复位，没运行则标用户待验。

输出参数表、实现配方、候选hash、可用预览和触发入口；性能目标从项目预算读取，不能由粒子数或静态代码推断真机通过。基准更改仅列影响范围，不擅自改所有现用材质/动画。
