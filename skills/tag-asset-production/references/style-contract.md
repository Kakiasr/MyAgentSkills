# 标签：统一完成度，保留每款视觉身份

新设计和风格修改时读取；局部修字只使用对应规则。minigame中通用方法复用同仓库[minigame静态风格契约](../../minigame-art-production/references/style-contract.md)，不复制项目参数到标签技能。其他项目仅用本页并读取其自身基线。若独立安装时同级静态技能不存在，使用本页两层简报、单款字段和项目事实源继续；明确共享参考未读，不为该依赖重新安装或复制整套技能，也不声称完整契约检查已通过。

## 两层简报

共同层固定现行构图、主体可辨识度、艺术字完整性、输出比例/边缘/显示尺度；单款层决定电影或专辑来源、媒介、色彩关系、字形、纹理与装饰。不同款可以是洛可可曲线或表现主义尖角，统一不意味着使用同一种字体、滤镜、阴影或印刷网点。

每款简报包括：

1. 已查看的参考及借鉴维度；文化/历史论断的依据与未知项。
2. 可观察的视觉支柱：例如尖角主体和字形共享节奏，而不是只写“表现主义”。
3. 颜色角色：主体、衬托、文字、结构、高光；按参考明确主次，不混合所有参考的色板。
4. 字形构造：语言与准确原文、宽窄、衬线/转角、笔画对比、字腔、基线、主副层级和分行；中文/非拉丁字缺字时给真实字形方案，不输出伪字。
5. 材质与构图：左主体/右文字及本款例外，允许纹理的层与区域，细节密度和实际显示尺寸。
6. 制作配方与Do/Don't：主体→衬托→艺术字→按实际规范导出，明确保护区；不照搬参考标题，不自动加装饰小字。

## 示例：把风格词变成检查项

“尖角、黑金、建筑感”可以落实为：主体与标题共用斜切方向；浅色字与暗底分离；建筑衬托不穿过字腔。色值、角度和大小仍须来自本款依据，不在技能示例中指定。成功是小尺寸仍可辨认主体和逐字阅读，失败是靠高光堆砌、细线消失或衬托压字；不是与原海报逐像素相似。

## 迭代与集合检查

生成前锁定共同层与本款层，之后只改变授权项。新候选与本款选定稿对照，再与其他正式标签以同显示尺度并排：检查主体视觉重量、文字层级、边缘完成度，不要求相同颜色/媒介。原生像素与游戏显示预览分开，高清源漂亮不能证明小尺寸可读。

交付引用简报版本、候选hash、逐字检查、原生/显示预览、明确例外与未验证项。获选候选才成为该款依据，未经确认不替换全局参考；单款确认不自动授权全套覆盖。
