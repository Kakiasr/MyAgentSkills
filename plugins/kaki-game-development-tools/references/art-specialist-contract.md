# 美术专项交接契约

## 分层

- `game-art-direction`拥有全项目视觉支柱、风格边界、全局可读性和美术圣经，不替专项设计具体内容。
- 角色道具、环境、UI、动画、VFX专项分别拥有本领域`VIS-*`规则和验收。
- 2D／3D生产专项拥有`AST-*`源文件、导出物、版本、授权和引擎交付记录，不擅自改视觉设计。
- 渲染技术美术拥有Shader、材质、灯光和后处理实现；资产管线拥有导入、检查与自动化；图形性能拥有预算、采样和优化证据。

## 最小交接

每次交接记录：目标与范围、输入`EXP/SYS/ACT/EVT/VIS/AST/NFR-*`、平台与镜头、确认项与未知项、所有者、输出路径、版本、验证环境和未执行检查。设计变更创建或更新`VIS-*`；资产生产使用`AST-*`；技术决定与测量使用`TA-*`／`NFR-*`。

## 边界

- 视觉设计不改变玩法数值、触发和胜负。
- 资产生产不以文件存在代替视觉或引擎验收。
- 渲染实现不重写设计意图；性能降级要回交受影响视觉所有者。
- UI视觉不拥有信息架构和交互规则；动画不拥有状态机真值；VFX不拥有伤害判定。
- 同一规则只在一个权威专项定义，其他技能引用ID，不复制维护。
