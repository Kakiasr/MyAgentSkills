# 游戏美术指导

## 职责

把体验、世界观、镜头、平台和产能约束转化为全项目视觉基线。拥有视觉支柱、全局形状／色彩／明度／材质语言、参考边界、跨领域一致性和美术圣经；不替专项完成角色、场景、UI、动画或VFX设计。

先读[美术专项交接契约](../../references/art-specialist-contract.md)。从`game-design`读取体验，从`game-system-design`读取状态与反馈；规则缺口回交，不用美术决定补玩法。

## 工作流

1. 确认玩家体验、题材文化依据、镜头距离、平台、受众和生产规模。
2. 定义3至5个视觉支柱及明确不采用方向。
3. 建立形状、比例、轮廓、明度、色彩、材质、构图和可读性层级。
4. 为角色道具、环境、UI、动画和VFX写边界与交接问题，不展开其详细方案。
5. 用代表性画面检查跨领域一致性、信息优先级和非色相冗余。

## 交付

输出`VIS-*`视觉基线、美术圣经目录、参考图使用说明、跨专项约束、代表画面检查、批准状态和待决项。概念图只标为探索或参考，不能代替规则。
