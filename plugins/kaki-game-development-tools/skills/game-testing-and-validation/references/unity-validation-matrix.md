# Unity验证矩阵

本矩阵整理自用户提供的《Unity项目开发规范》。按项目实际功能裁剪，不存在的模块标记不适用，不为满足清单虚构系统。

## 分层

| 层级 | 主要检查 |
| --- | --- |
| 静态／编辑器 | asmdef循环、编译、缺失引用、重复ID／事件源、配置范围、Prefab断链、Build Settings |
| EditMode | 纯规则、公式、候选池、状态转移、事件载荷、序列化迁移 |
| PlayMode | 开局、暂停、结束、连续重开、生成／回收、订阅解绑、场景连接 |
| Build Smoke | 目标平台启动、输入、字体、Sorting、资源引用、场景切换、存档路径 |
| 手工体验 | 操作反馈、镜头、时序、可读性及无法可靠自动化的表现 |

## Unity提交前基线

- C#编译零错误；警告按项目门禁处理。
- 新增或改名序列化字段已检查旧Prefab、场景和资产迁移。
- 新事件存在发送者、订阅者、解绑路径和至少一个行为验证。
- 连续重开至少三次，无旧实体、库存、分数、计时器、异步任务或UI残留。
- 不受暂停／慢动作影响的组件使用明确的非缩放时间。
- 目标平台输入语义一致，差异已记录。
- 构建所需字体、Sprite、Prefab、场景和配置均为可追踪引用。
- 采用中文创作界面时，设计师可见Inspector标签和Tooltip符合项目语言规范。
- 玩家可见字符在TMP动态字体或授权Fallback中可用；在实际目标平台检查缺字。

## 验证器建议

- Scene Wiring：Director、System、EventSource和关键锚点缺失。
- Event Source：重复权威实例、事件签名和订阅生命周期。
- Prefab：Actor、Collider、Renderer、Definition和禁止的场景引用。
- Config：范围、必填、空候选池、重复主键和升级链。
- Audio/FX Binding：事件、签名、目标方法和资源缺失。
- Font：TMP Settings、Fallback、授权和项目字符覆盖。
- Build Scene：启动场景、Gameplay场景、平台设置和必要资产。

每个验证器必须输出具体资产／对象／字段；不允许只有“验证失败”。自动修复应先预览，并能撤销或由版本控制恢复。
