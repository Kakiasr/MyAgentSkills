# 游戏角色与道具设计

## 职责

拥有角色、生物、服装、武器、装备和交互道具的视觉规则与生产简报。引用`game-art-direction`的全局基线，不负责场景、UI、动画制作或3D建模。

先读[美术专项交接契约](../../references/art-specialist-contract.md)。

## 工作流与交付

1. 提取角色功能、阵营、能力、镜头占比、状态和装备关系。
2. 定义轮廓、比例、解剖／结构、形状语义、材质、配色和辨识距离。
3. 覆盖正侧背、关键表情、状态差异、变体规则、装备挂点和遮挡风险。
4. 为2D或3D生产交付尺寸／比例、分层、材质、可动区域、禁止改动项和`AST-*`清单。

验收必须检查剪影识别、角色间差异、状态可读性、文化依据、变体一致性和目标镜头中的表现。
