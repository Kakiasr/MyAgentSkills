## 定制内容

默认目标从通用软件调查改为游戏拆解：配置／规则／体验／内容／经济／成长／循环；把实现证据转写成触发、目标、效果、数值、次数、时点、例外。保留源码与实际行为冲突、验证分层、系统树原图例及稳定ID；需要时交接其他游戏专业技能，而不是以恢复工程代替需求。

原技术正文仅作以下适配：标题、引用路径指向随包上游参考；收尾明确只关闭自建会话。新增中文入口与部署覆盖规则，不静默删去原技术段落。上游setup原文保留，但不因调用本技能就执行另一套全局注册。

## 升级校核

升级时从官方发布包取得匹配版本的技能、六个参考与许可证；更新release.json并核对下载完整性。对照完整技术正文确认无段落或路由被遗漏，再验证实际运行时身份与tools/list，不能只匹配207这个数量。独立记录连接、样本分析、原生反编译及游戏特定路线的测试，不因一个通过而覆盖全部能力。
