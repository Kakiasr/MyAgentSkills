# 游戏UI视觉设计

## 职责

拥有HUD、菜单、界面组件、图标、字体、布局令牌、视觉状态和无障碍视觉规则。信息架构与交互流程来自系统／UX需求；Unity uGUI或UITK实现交给对应Unity技能。

先读[美术专项交接契约](../../references/art-specialist-contract.md)。

## 工作流与交付

1. 建立屏幕、组件和状态清单，明确重要性、频率、输入方式、安全区和本地化需求。
2. 定义栅格、间距、字号、图标、边框、层级、色彩、焦点、禁用、错误和加载状态。
3. 验证不同分辨率、长文本、键鼠／手柄／触屏、色觉缺陷和运动减弱模式。
4. 输出组件`VIS-*`、设计令牌、状态矩阵、切图／九宫格／字体`AST-*`及逐屏验收。

不得用视觉稿替代交互规则，也不得仅交付静态正常态。
