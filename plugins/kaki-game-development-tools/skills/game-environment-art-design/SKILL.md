# 游戏环境美术设计

## 职责

拥有场景、建筑、地形、生态区、模块套件、陈设和环境叙事的视觉方案。引用关卡功能和全局美术基线，不改变碰撞、导航或关卡规则。

先读[美术专项交接契约](../../references/art-specialist-contract.md)。

## 工作流与交付

1. 提取空间功能、玩家路径、视距、地标、危险、交互物和昼夜／天气状态。
2. 定义空间层次、建筑语言、尺度、模块网格、材质家族、色彩分区和灯光意图。
3. 建立地标、路径、边界、危险与奖励的视觉编码，避免仅靠色相。
4. 输出区域`VIS-*`、模块套件、陈设密度、状态变体、2D／3D资产需求及最差视角验收。

技术灯光和Shader实现交给`game-rendering-technical-art`；模型与贴图生产交给对应资产生产技能。
